This repository contains the backend implementation for the Blog Site Application.
It is built using Node.js, Express, MongoDB, and follows a microservices-based architecture with JWT authentication.

📌 Overview

The backend is responsible for:

User registration and authentication

Blog creation, deletion, and retrieval

Public blog discovery with filters

Secure access using JWT

Separation of concerns using multiple services

🏗️ Architecture
Client (React UI)
      |
      v
API Gateway (Port 4000)
      |
      ├── User Service (Auth & Identity)
      └── Blog Service (Blog Domain)

Key Concepts Used

Microservices Architecture

RESTful APIs

JWT-based Authentication (Stateless)

Express Middleware

Repository Pattern

CQRS (Command / Query separation in blog service)

📦 Services
1️⃣ User Service

Responsible for user identity and authentication.

Features

User Registration

User Login (JWT Token Generation)

Database

MongoDB (Users collection)

2️⃣ Blog Service

Responsible for blog management and discovery.

Features

Create Blog (Authenticated)

Delete Blog (Authenticated & Ownership-based)

Get blogs created by authenticated user

Get all public blogs

Filter blogs by category and date range

Database

MongoDB (Blogs collection)

🔐 Authentication & Security

Authentication is handled using JWT (JSON Web Tokens)

JWT is generated by User Service and validated by Blog Service

Same JWT_SECRET is shared across services via environment variables

Protected routes require:

Authorization: Bearer <JWT_TOKEN>

Token Handling

Stateless authentication

Token expiry handled via JWT exp

Expired tokens return 401 Unauthorized

📡 API Endpoints
🔹 User Service
Method	Endpoint	Description
POST	/api/v1/blogSite/user/register	-- Register a new user


POST	/api/v1/blogSite/user/login	--Login & receive JWT


🔹 Blog Service (Authenticated)
Method	Endpoint	Description
POST	/api/v1/blogSite/user/blogs/add	-- Create a new blog


DELETE	/api/v1/blogSite/user/blogs/delete	-- Delete a blog (own blog only)


GET	/api/v1/blogSite/user/blogs/getall	-- Get blogs created by logged-in user


🔹 Blog Service (Public)
Method	Endpoint	Description
GET	/api/v1/blogSite/blogs/getall	-- Get all public blogs


GET	/api/v1/blogSite/blogs?category=&startDate=&endDate=	-- Filter public blogs
🧪 Validation Rules
User Registration

All fields mandatory

Email must be valid

Password must be alphanumeric

Minimum password length enforced

Blog Creation

Blog name ≥ 20 characters

Category ≥ 20 characters

Article ≥ 1000 words

All fields mandatory

Timestamp generated by backend


Environment Variables

Each service uses its own .env file.

Common Variables
PORT=XXXX
MONGO_URI=mongodb://localhost:27017/blogsite
JWT_SECRET=your_shared_jwt_secret


⚠️ JWT_SECRET must be the same across all services

🚀 Running the Backend
Install Dependencies
npm install

Start Services
npm start


Make sure:

MongoDB is running

API Gateway is running on port 4000

User and Blog services are running on their respective ports

Swagger is running on /api-docs path under gateway, e.g., http://localhost:4000/api-docs
